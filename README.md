# AI 디지털 기반 교실의 변화, 교사는 무엇을 설계하는가

교사·대학원생 대상 약 50분 특강용 발표·자료 겸용 웹앱

## 파일
- `index.html` — 웹앱 전체 (이 파일 하나만 GitHub에 올리면 됨)
- `Code.gs` — 실시간 응답·투표용 Google Apps Script 백엔드

## 1. 실시간 응답 연결 (구글 시트)
1. 새 구글 스프레드시트 만들기 → **확장 프로그램 → Apps Script**
2. `Code.gs` 내용을 붙여넣고, 맨 위 `ADMIN_KEY`를 리셋용 암호로 바꾼 뒤 저장
3. **배포 → 새 배포 → 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
4. 발급된 URL(`…/exec`)을 `index.html` 상단 `CONFIG.SCRIPT_URL`에 붙여넣기

응답은 시트의 `responses` 탭에, 강의 회차는 `sessions` 탭에 쌓입니다.
- `opening` 여는 질문 / `poll` 투표 / `etc` 투표 기타 응답 / `closing` 마무리

## 강의마다 새로 시작하기 (리셋)
- 투표 슬라이드 오른쪽 아래 **↺ 새 강의 시작 (리셋)** → 강의 이름 입력 → 관리자 암호(`ADMIN_KEY`) 입력
- 여는 질문·투표·마무리 보드가 모두 비워지지만 **이전 데이터는 지워지지 않습니다.**
- **📊 이전 강의 결과 보기**를 누르면 회차별 투표 결과와 기타·여는 질문·마무리 응답을 볼 수 있습니다.
- 리셋 버튼은 참석자용 자료 모드(휴대폰)에서는 보이지 않습니다.

URL을 비워 두면 '체험 모드'로 동작합니다(응답이 그 기기에서만 보임).
투표는 강의 회차마다 기기당 1회입니다. 리셋하면 같은 기기로 다시 투표할 수 있어요.

## 2. GitHub Pages 배포
1. 새 저장소에 `index.html` 업로드
2. **Settings → Pages → Branch: main / (root)** 저장
3. `https://ywan2026.github.io/<저장소>/` 로 접속

## 사용법
- **발표 모드**: ← → / Space로 넘기기, `F` 전체 화면, `D` 발표·자료 전환
- **참석자용 링크**: 주소 뒤에 `?mode=doc` → 스크롤형 자료 (표지 QR이 이 주소로 연결)
- 휴대폰으로 접속하면 자동으로 자료 모드로 열립니다.
- **PDF 다운로드**: 상단 버튼 → 인쇄 창에서 'PDF로 저장'
- **타이머**: 하단 ⏱ 클릭 시작·정지, 더블클릭 초기화 (기준 50분)
