# AI 디지털 기반 교실의 변화, 교사는 무엇을 설계하는가

교사·대학원생 대상 50분 특강용 발표·자료 겸용 웹앱 (AI와 독서교육 특강과 같은 구성, 파란색 테마)

## 파일
- `index.html` — 웹앱 전체. 이 파일 하나만 GitHub 저장소(ai-teacher)에 올리면 됩니다.
- `Code.gs` — 실시간 응답 백엔드 (이미 배포한 것과 같음, 다시 배포할 필요 없음)

## 화면 구성
- 왼쪽 목차(사이드바), 위쪽 메뉴: 발표 · 자료 · 참고문헌 · ▦ QR 접속 · ⬇ PDF 저장 · 📊 이전 결과 · ↺ 새 강의
- 참석자는 표지 QR 또는 [QR 접속]으로 들어오면 자료 모드로 열립니다. 휴대폰은 자동으로 자료 모드.
- 단축키: ← → 넘기기, F 전체화면, D 발표/자료 전환

## 실시간 응답
- 여는 질문, 마무리 질문 두 곳 (구글 시트 `responses` 탭)
- **↺ 새 강의**: 강의 이름 + 관리자 암호(`Code.gs`의 ADMIN_KEY) → 보드가 비워지고 이전 응답은 보관
- **📊 이전 결과**: 강의 회차별 응답 보기

## PDF
- **⬇ PDF 저장**을 누르면 인쇄 창이 열립니다. 대상을 'PDF로 저장'으로 고르면 16:9 슬라이드 1장이 1쪽인 PDF가 만들어집니다.
- 뉴스 이미지 3장(ChatGPT, AI 안경, AI 콘택트렌즈)은 언론사 서버에서 불러오므로, 인터넷에 연결된 상태에서 저장하세요.

## 링크 바꾸기
`index.html` 안의 `CONFIG`에서 패들렛·앱·Brisk 링크를, `NEWS_IMG`에서 뉴스 이미지 주소를 바꿀 수 있습니다.
